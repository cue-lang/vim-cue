==============================================================================
INTRO                                                                  *cue-intro*

vim-cue is a filetype plugin for the CUE language (https://cuelang.org). It
provides filetype detection for *.cue files, syntax highlighting, indentation,
and syntax-based folding.

Features that require understanding CUE semantics -- formatting, diagnostics,
completion, and navigation -- are not implemented by this plugin. They are
provided by the CUE language server; see |cue-lsp|.

==============================================================================
INSTALL                                                              *cue-install*

See the README for installation instructions covering the common Vim plugin

==============================================================================
LANGUAGE SERVER                                                          *cue-lsp*

Formatting and diagnostics are provided by the CUE language server, which is
built into the `cue` command and started with: >

  cue lsp
<
Configure your LSP client to launch `cue lsp` for the `cue` filetype, with the
project root resolved to the directory containing the enclosing `cue.mod`. Any
LSP client works -- for example Neovim's built-in LSP, vim-lsp, or coc.nvim;
register a server whose command is `cue lsp`. Formatting on save is then
configured through that client rather than by this plugin.

Earlier versions of this plugin shelled out to `cue fmt` on save via a
`:CueFmt` command and a `g:cue_fmt_on_save` option, and shipped a Syntastic
checker for diagnostics. These have been removed: both formatting and
diagnostics are now the language server's responsibility.

==============================================================================
FOLDING                                                              *cue-folding*

The plugin enables syntax-based folding for *.cue files, setting 'foldmethod'
to "syntax" and 'foldlevel' to 100 when a CUE file is opened.
